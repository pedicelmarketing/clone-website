## Evidence basis

For each section above, tag the evidence basis:

- `Observed visually` — the human saw it.
- `Interaction-tested` — the human interacted with it.
- `DOM+assets confirmed` — the script measured it.
- `HTTP-200 only` — the page returned but the measurement failed.
- `Not exercised` — the step was skipped.

A `Fidelity Gap` is anything missing from the reference, frozen, disabled, replaced, or
substantially downgraded here. List every gap explicitly.
