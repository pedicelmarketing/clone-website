## Motion evidence summary

- **Observed motion system(s) and evidence:** no third-party animation library is present. The bundle scan found no GSAP, Framer Motion, Lenis, Locomotive, Swiper or Embla markers. Motion comes from three sources: (a) Tailwind CSS transitions and three `@keyframes` (`enter`, `exit`, `spin`) in the captured CSS chunks; (b) hand-rolled JS scroll/observer work — `IntersectionObserver` ×10, `addEventListener("scroll")` ×11, `useScroll` ×3, `ResizeObserver` ×21, `requestAnimationFrame` ×55; (c) React Three Fiber's render loop on `/en/3d` (`useFrame` ×16).
- **Shared measured values:** default transition duration **`.65s`** (Tailwind `--tw-duration` default, appearing 10×), one component at **`.9s`**; easing **`cubic-bezier(.4, 0, .2, 1)`** and `var(--ease-in-out)`; animation delays **`0s` / `.2s` / `.5s`** (staggered reveals). Transition property groups observed: `all`, `opacity`, `width`, `height`, `grid-template-rows`, `overflow`, `transform,translate,scale,rotate`, `color,box-shadow`.
- **Declared states exercised:** page load and **full-page scroll to bottom**, at desktop and mobile viewports, on all 10 routes (14–16 scroll steps, 700–800 ms per step, bounded settle ≤6 s). Scroll mechanism was `window_scroll` everywhere — no virtual or internal-container scrolling. This exercised rows 1–5, 7, 8 and 10.
- **Blocked, unexercised, or uncertain behavior:**
  - Rows 6, 9 and 11 are **`Not exercised`** — accordions, menu/modal enter-exit transitions and the `popup.mp4` modal are all click-gated, and click interaction was outside the declared coverage. Their CSS and assets are present in the mirror; their behavior is unverified.
  - Row 10's interactive behavior (camera orbit, building/unit selection) is unexercised. Whether the scene reaches a usable terminal render state is recorded in `validation-report.md` from the browser matrix, not assumed here.
  - Row 4's exact scrub mapping (scroll distance → translate distance) was not measured; only the mechanism is confirmed.
  - No preloader or staged entry gate was observed on any route, so the WebGL-module "progress indicator stalls" check does not apply — with the exception of `/en/3d`, whose terminal state is reported in the validation report.
